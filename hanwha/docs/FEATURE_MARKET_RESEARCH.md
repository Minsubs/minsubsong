## 1. 요약

**핵심 결론 5줄**

1. **우리 핵심 가치("10구단 예매 오픈을 한 곳에서 push로 안 놓치게")를 같은 방식으로 정면 제공하는 곳은 사실상 없다.** Total Base·오늘야구가 통합 캘린더로 가장 닮았고, 직관메이트가 팀별 오픈 푸시를 하지만 **Android 단독**이며, 공식 앱(KBO·롯데)은 평점 2.1로 신뢰가 붕괴돼 있다 → 빈틈이 실재한다.
2. **가장 강한 미충족 수요는 "취소표/예매 타이밍 알림"과 "우천취소 갈까말까 실시간 알림"** 두 가지다. 둘 다 우리 원칙(자동예매·스크래핑 금지)과 충돌 없이 Web Push로 직접 해소 가능하다 — 즉 백엔드 로드맵 P1/P2와 정확히 맞물린다.
3. **글로벌 traction의 본질은 "거래"가 아니라 그 위의 "알림·정보 레이어"**(SeatGeek 가격 드롭 알림, Gametime 라스트미닛)다. 우리는 거래를 안 하므로 정보 레이어만 떼어오면 정합적이며, 2025 개정 암표법(재판매·중개 책임 강화)은 오히려 "거래 안 하고 알림만 주는" 우리 포지션의 안전성을 높여준다.
4. **명백한 레드오션/우리가 못 이길 영역**: 좌석뷰 사진 DB(자리어때 12.9만 장·평점 4.9), 직관 기록 다이어리(하루1루·직꾸 등 10종+ 난립), 디지털 티켓/입장(구단·예매처 소관) — 직접 구축은 비효율, 외부 링크 안내로만.
5. **수익화는 트래픽이 없으면 의미 없다.** 티켓 예매처는 성과형 어필리에이트를 공개 운영하지 않아(배너 광고 위주) 1차 BM이 못 된다. 가장 깨끗하고 즉시 가능한 건 **여행/숙박 어필리에이트(화면 내 컨텍스트 추천, 푸시 아님)** 이고, 정공법은 **프리미엄 구독이지만 지불의사가 unknown이라 검증 탭 선행**이 필요하다.

**추천 추가기능 Top 5 (각 한 줄, 우선순위순)**

1. **예매 오픈 임박 푸시 (내 구단 개인화)** — 우리 핵심 무기. 경쟁 갭(iOS/PWA·통합·신뢰성) + 최강 수요 + 원칙 무충돌. 백엔드 P1.
2. **우천취소/경기상태 "갈까말까" 실시간 푸시** — 강한 페인 + Web Push 친화 + 코스트 낮음 + 차별화 좋음. 백엔드 P3 인근 신규.
3. **구단 프로모션/이벤트 일정 통합** — 백엔드 전에도 가능. 우리 캘린더 강점 자연 확장, MLB Ballpark 벤치 이식 가능.
4. **선예매/선선예매 개인화 알림 (내 멤버십 기준)** — 아무도 안 하는 빈틈. selectedTeam 자산 활용. 캘린더 정확도 강화와 묶음.
5. **여행/숙박 어필리에이트 (원정 구장 근처 숙소, 화면 내 추천)** — 유일하게 즉시 가능한 깨끗한 수익화. 원정 직관 페인 + 캘린더 데이터 결합.

### 2.2 빈틈 — 아무도 잘 안 하거나 비어 있는 곳

1. **"예매 오픈 직전" 사전 push** — 예매처는 "취소 발생 후" 대기만, 공식·네이버는 경기/결과 알림만. **오픈 임박 사전 알림을 10구단 통합 + iOS 포함으로 안정 제공하는 곳이 없음.** ← 우리 핵심 무기와 정확히 일치. 단 직관메이트가 Android에서 함 → **차별점은 "iOS/PWA + 신뢰성 + 통합 캘린더 완성도".**
2. **iOS·PWA 공백** — 직관메이트는 Android 단독, 오늘야구는 웹, 공식 앱은 평점 2.1. **"가볍고 설치 없는 PWA + 잘 도착하는 push"** 포지션이 비어 있음.
3. **선예매/선선예매 개인화** — 오늘야구가 "조건 비교"는 하지만 **"내 멤버십 기준 나에게 적용되는 선예매 시각만 골라 알려주는"** 개인화는 비어 있음(selectedTeam 자산 활용 여지).
4. **신뢰 가능한 단일 출처 캘린더** — 구단마다 예매처/시각 제각각(롯데 자체앱 / LG·두산·키움 인터파크 / 나머지 티켓링크) + 공식 앱은 날씨도 2020년 고정. **"정확하고 최신인 10구단 오픈 일정" 자체가 신뢰 갭.**
5. **예매처 딥링크 + 정확한 오픈시각 카운트다운**을 한 화면에 묶는 곳 부재.

## 3. 팬 페인포인트 / 수요

**시장 맥락(수요의 토대):** KBO 관중 2024년 1,088만 → 2025년 1,231만 사상 최대. 2025시즌 매진율 폭증(703경기 중 약 45.7%=321경기 매진, 전년 221경기 대비 급증). 신규 유입 핵심이 20~30대 젊은 여성. → **"티켓 구하기 어렵다 + 직관 처음이라 모르겠다"** 페인이 구조적으로 커지는 중이고, 우리 핵심 가치와 정확히 맞물린다.

- **검증 탭으로 프리미엄 지불의사·기능 묶음 수요 측정** — 수익화 2순위(구독) 결정의 선결. (단 현재 localStorage라 합산 불가 → 9.1 참조.)

## 8. 미해결 질문 / 다음 검증

**사용자 결정 필요:**

1. **추가 기능 우선순위 확정** — 본 문서 Top 5 중 백엔드 P1(예매 오픈 푸시) 외에 어디까지 동시 추진할지. (특히 "우천취소 푸시"를 P3보다 앞당길지 — 수요 강도는 높음.)
2. **수익화 착수 여부** — 여행/숙박 어필리에이트를 지금 붙일지(트래픽 작아도 컴플라이언스 학습 가치) vs 트래픽 쌓고 나서. 붙인다면 공정위 표기 카피 + 푸시/광고 채널 분리 정책 명문화(`BACKEND_PUSH_PLAN` 8장 #5와 묶음).
3. **프리미엄 구독 검증 설계** — 검증 탭에 가격대·기능 묶음 질문을 추가해 지불의사 측정할지. (선결: 검증 집계 백엔드 — 9장.)
4. **선예매 개인화 데이터 범위** — "내 멤버십 기준 선예매 시각"을 위해 멤버십 종류를 사용자가 입력하게 할지(개인정보 최소화 vs 개인화 트레이드오프).

**Unknown 추적 (확인 못 함 — 결정 전 재검증):**

- 직관메이트 평점·다운로드·취소표 유무 / Total Base·오늘야구 알림이 진짜 Web Push인지(메일·구독형 가능성) → **경쟁 위협도 재평가에 필요.**
- 매치클락 등 동행 앱 활성 사용자 규모 → 동행 기능 수요 크기.
- 티켓 예매처 성과형 어필리에이트 채널 존재 여부(사실상 미운영 추정) / 소형 앱의 KBO·구단 공식 파트너 진입 경로.
- "예매 오픈 푸시" 단독 가치의 구독 지불의사 → **검증 탭으로 측정해야 할 핵심 unknown.**
- 원정 직관 정보(주차·교통)의 신뢰 데이터 소스 확보 가능성(공식/제보 한정).

> 본 문서의 모든 unknown은 추정으로 채우지 않았다. 의사결정 직전 1차 출처(스토어 페이지·예매처 공지·법령) 재확인을 권장한다.
