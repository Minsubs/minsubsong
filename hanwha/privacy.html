KBO TIDO · 초안 2026-07

1. 총칙

KBO TIDO(이하 “서비스”)는 KBO 10구단 예매 오픈 일정과 경기 알림을 제공하는 개인 운영 무료 웹앱입니다. 서비스는 개인을 식별할 수 있는 정보(이름·이메일·전화번호·계정·위치 등)를 수집하지 않는 것을 원칙으로 설계되었습니다.

2. 처리하는 정보와 목적

항목 내용 목적 저장 위치
푸시 구독 정보 브라우저가 발급한 익명 push endpoint URL, 메시지 암호화 키(p256dh/auth), 구독 주제(팀 코드+알림 종류, 예: HH:ticket_open) 사용자가 켠 알림(예매 오픈·주간 브리핑·경기 알림)의 발송 서비스 서버(Cloudflare Workers/D1)
발송 기록 endpoint별 발송 완료 키(중복 발송 방지용), 발송 시각 같은 알림의 중복 발송 방지(경기당 1회 등) 서비스 서버
익명 수요 집계 일자별 카운터(예: 특정 팀 관심 수) — 개인 단위 행 없음 서비스 개선을 위한 총량 통계 서비스 서버
앱 설정·신호 내 구단, 알림 토글, 관심 경기, 수요 검증 신호 등 개인화 표시 이용자 기기(localStorage)에만 저장, 서버 미전송

서비스 서버에는 IP 주소, User-Agent, 기기 식별자, 쿠키, 위치정보를 저장하는 컬럼이 없으며, 어떠한 개인 식별 정보도 데이터베이스에 기록하지 않습니다. 푸시 endpoint는 로그에도 평문으로 남기지 않습니다(마스킹 처리).

3. 보유 기간

  • 푸시 구독 정보: 알림 해제(구독 취소) 시 즉시 삭제됩니다. 브라우저가 구독을 만료시킨 경우(발송 실패 410/404)에도 삭제됩니다.
  • 발송 기록: 중복 방지 목적 달성 후 주기적으로 정리됩니다.
  • 기기 내 설정: 이용자가 브라우저 데이터 삭제 또는 앱 내 초기화로 언제든 삭제할 수 있습니다.

4. 제3자 제공 및 처리 위탁·국외 이전

  • 개인정보를 제3자에게 판매·제공하지 않습니다.
  • 서버 인프라는 Cloudflare, Inc.(미국)의 Workers/D1을 사용합니다. 위 §2의 익명 구독 정보가 Cloudflare의 글로벌 엣지 인프라에서 처리·보관됩니다.
  • 푸시 메시지 전달은 이용자의 브라우저 제조사 푸시 서비스(Google FCM, Apple APNs, Mozilla 등)를 경유합니다(웹 표준 Web Push 동작).
  • 경기장 날씨는 브라우저가 Open-Meteo(비영리 오픈 API)에 직접 요청합니다. 요청에는 사용자의 위치가 아닌 경기장 좌표가 사용되며, 통신 특성상 IP 등 일반 요청 정보가 제공자에게 전달됩니다.
  • 정적 페이지 호스팅: GitHub Pages(GitHub, Inc., 미국).

5. 알림(푸시)의 성격과 수신 동의

  • 모든 알림은 이용자가 알림 센터에서 항목별로 직접 켠 것만 발송되는 수신자 요청 정보성 알림입니다(광고성 정보 아님).
  • 각 알림 카테고리는 기본 꺼짐(OFF)이며, 켤 때 어떤 내용이 오는지 항목별로 표시합니다.
  • 알림 끄기: 앱 내 종 버튼/알림 센터에서 원탭으로 해제할 수 있고, 해제 시 서버의 구독 정보가 삭제됩니다. 브라우저 설정에서도 차단할 수 있습니다.
  • 야간 발송 제한: 기본적으로 KST 22:00~08:00에는 발송하지 않습니다(진행 중 경기 알림만 경기일 23:30까지 예외).

6. 이용자의 권리

이용자는 언제든 ①알림 해제(=서버 구독 정보 삭제) ②기기 내 데이터 초기화 ③아래 연락처를 통한 문의·삭제 요청을 할 수 있습니다. 서비스에 계정이 없으므로 별도 탈퇴 절차는 없습니다.

7. 아동의 개인정보

서비스는 연령 정보를 수집하지 않으며, 만 14세 미만 아동을 대상으로 하는 서비스가 아닙니다.

8. 안전성 확보 조치

  • 서버 저장 정보에 개인 식별 컬럼 자체를 두지 않는 최소화 설계
  • 푸시 발송 개인키는 서버 비밀 저장소(Cloudflare Secret)에만 보관
  • endpoint 로그 마스킹, HTTPS 전 구간 적용, 허용 출처(CORS) 제한
